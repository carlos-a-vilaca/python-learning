# Log Analysis Exercises

Coleção de exercícios práticos de análise de logs realizados durante o estudo de Cibersegurança.

## Objetivos dos Exercícios

- Analisar ficheiros de log
- Organizar informação relevante
- Categorizar eventos e tipos de erros
- Estruturar resultados por módulos
- Produzir estatísticas dos dados analisados
- Desenvolver competências de investigação e documentação

## Competências Trabalhadas

- Log Analysis
- Data Organization
- Error Classification
- Technical Documentation
- Windows Command Line
- Cybersecurity Fundamentals
