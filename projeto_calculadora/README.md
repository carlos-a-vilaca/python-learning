#Calculadora Interativa 

Programa em Python que simula uma calcualdora interativa com menu, 
com várias operações matemáticas e tratamento de erros.

## Funcionalidades 
-Calculadora básica(SOMA, SUBTRAÇÃO, MULTIPLICAÇÃO, DIVISÃO)
-Tabuada de um número 
-Verificação de par ou ímpar
-Verificação de números primos 
-Cálculo de faturial 

## Como executar 
1. Corre o ficheiro main.py: python main.py
2. Segue as instruções do menu 

## Estrutura do projeto
-main.py - programa principal com menu 
-calculadora.py - módulo que contem todas as funções (calculadora, tabuada, par ou impar, numeros primos, faturial)
-README.md - este ficheiro
