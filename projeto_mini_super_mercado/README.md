# Supermarket System

Projeto desenvolvido em Python no âmbito da aprendizagem de programação e consolidação dos conhecimentos adquiridos ao longo da formação.

## Descrição

Este projeto simula um sistema simples de supermercado, permitindo a gestão de produtos, o registo de compras e a emissão de um talão final.

O principal objetivo foi aplicar, de forma prática, diversos conceitos fundamentais de Python estudados durante a formação, integrando-os num projeto único e funcional.

---

## Objetivos de Aprendizagem

Durante o desenvolvimento deste projeto foram aplicados conhecimentos de:

- Variáveis e tipos de dados
- Estruturas condicionais
- Ciclos de repetição
- Funções
- Listas e dicionários
- Manipulação de dados
- Formatação de texto
- Modularização do código
- Tratamento de erros e exceções

---

## Funcionalidades

- Consulta de produtos disponíveis
- Adição de produtos ao carrinho
- Atualização de quantidades
- Cálculo automático de subtotais
- Aplicação de descontos
- Cálculo do valor total da compra
- Emissão de talão com data e hora
- Validação de dados introduzidos pelo utilizador
- Tratamento de exceções para evitar erros durante a execução

---

## Tratamento de Erros e Exceções

Foram implementados mecanismos de validação e tratamento de exceções para melhorar a experiência do utilizador e aumentar a robustez da aplicação.

Exemplos:

- Introdução de valores inválidos
- Conversão incorreta de tipos de dados
- Entradas vazias
- Seleção de opções inexistentes
- Quantidades inválidas
